# 《优势在我》配图

全部为**程序化生成的矢量插画（SVG）**，零外部依赖、零 API、零成本；同目录附位图版（`png/`）与六幕的 JPEG。

重新生成：

```bash
npm run art                                        # 生成 9 张 SVG
node assets/campaigns/neike/art/rasterize.mjs      # 用本机 Chrome 光栅化成 PNG（+ 六幕的 JPEG）
```

生成是**确定性的**（脚本内固定随机种子），同一份脚本跑两次结果完全一致。

## 美术方向

**军事指挥所 + 病历档案**，冷色调（青灰 / 铅白打底，台灯的一小点暖橙作唯一高光）。画面里只出现：作战地图、沙盘、摊开的病历纸、化验单、红蓝铅笔、老式电话与电报稿、值班室的钟、走廊尽头的灯、印章、排班表。构图把「纸与地图」放在中间，四周留可裁切余量。

一条铁律：**画面里没有人。**

> 这条约束**在代码层面即成立**——`make-art.mjs` 里没有任何一处绘制人、手、背影、人影的路径，也不绘制血、器官、针头、导管或任何侵入性器械。这不是靠提示词祈祷出来的，是它根本画不出来。
>
> 同理：画面里的文字只有编号（`01`–`07`）与示意性的笔迹线条，没有可读的字句。

## 接进 Web UI

前端 `web/index.html` 的 `ACT_ART` 表按幕 id 引用这些图，随主线的 `phaseId` 自动切换；点幕图可展开全幅画卷灯箱，灯箱内可切换「电影概念大片（jpg）」与「典籍矢量画卷（svg）」两档。
