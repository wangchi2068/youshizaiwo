## 一、是什么 / 为什么适合这套架构

原回答的好笑不在医学，在**结构性错位**：每个科室都只看得见自己那条战线，却一律使用最高统帅部的语气——奥美拉唑是「阻击质子泵兵团」，碳酸钙是「监视骨代谢」，二氧化碳分压 40 对 50 就算「优势在我」。**指标变成战报，会诊变成联合作战会议。**

这正好命中运行时已有的三件套：

| 原作笑点 | 运行时机制 | 对应关系 |
| --- | --- | --- |
| 各科室各说各话、各自「战略部署」 | 派系系统（`sys-factions`） | 七个科室 = 七个派系，此消彼长 |
| 「病程记录」「会诊意见」怎么写就怎么算 | **经文机制**（本战役的签名机制） | 病历 = 经文。本来就格式化、本来谁写谁算、本来有法律效力 |
| 主治必须拍板 | 神谕卡（`decision-card`） | 医嘱 / 会诊意见 |
| 血压骤降、痰培养回报、造影剂过敏 | 掷骰（`roll-card`） | 真随机的并发症 |
| 夜班躲不掉 | `autoAdvance` 强制锚点 | 急会诊必到 |

**病历即经文**是本战役最强的机制对应：蚂蚁把神随手一踩记成「天罚」，而病历把「主治半夜一个人拍的板」记成「经全科讨论后决定」。前者的讽刺是宗教的，后者是体制的——而且**读者一看就懂，不需要任何设定铺垫**。

## 二、玩家是谁

**玩家 = 当班主管医生（住院总）。** 不是病人，不是某个科，不是主任。

理由：临床真正的张力不是「某个科对不对」，而是**每个科单独看都对、合起来互相打架**——激素升血糖所以要上胰岛素，R-CHOP 压骨髓所以要等血象，而 tspot 阳性又要回头评估，你想往前走一步，就有另一个科举手说「等一下」。这个「局部正确、全局冲突」的张力，恰好可以用状态变量建模，也恰好是玩家能用「随手」制造后果的地方。

**主任**是只在下命令的**上级压力**（像蚁后之于巢群：务实、不谄媚、握着玩家的职业命运），**不是**可扮演角色。

## 三、六幕（与原作段落的对应）

| 幕 | 情境 | 取自原作 | 核心玩法 |
| --- | --- | --- | --- |
| 一 · 入院 | 病人来了，你先得给一个初步判断 | 框架（原作未写入院） | 建立阵地：选收治方向，第一个科室被叫来 |
| 二 · 会诊 | 各科鱼贯而入，各交一份「战略构想」 | 内分泌「锁链式构想，确如常山之蛇」；风湿「刘医生，你记一下，我做如下战略部署」 | **派系登场**：同一份病历，七种解读 |
| 三 · 战报 | 化验单与影像雪片般回来，战线每天变 | 感染科 NGS「我没有理由否定……可是我又说服不了我自己」 | **经文机制开启**：病历开始写，且开始歪 |
| 四 · 矛盾 | 治疗互相打架，必须有人让路 | 血液科「先是迟迟不愿上 R-CHOP，还要心内消化内分泌先评估」 | **神谕卡**：你拍板，代价落在某个轴上 |
| 五 · 夜班 | 急转直下，躲不掉 | 心内「今日拂晓，患者出现数十次电风暴，除颤仪电量损失过半」 | **强制锚点**（`autoAdvance`） |
| 六 · 交班 | 晨会，病历被当众念出来 | 呼吸科「肺脏古战场……优势在我」 | **结局**：念的是病历，还是事实 |

### 各幕要点（可直接落进 `arc.json`）

**第一幕 · 入院**
- 目标：在信息极少的条件下给出初步判断，并决定先叫哪个科
- 铁律：不许玩家一上来就开全套检查——先让他在「不全的信息」里选
- 收尾钩子：第一个科室到场，带来一套宏大但只覆盖一条战线的构想

**第二幕 · 会诊**
- 目标：听完全部科室的「战略部署」，看清它们各自的盲区
- **mustEvents**：至少三科各交一份构想；出现第一次「两科意见直接冲突」；护士长第一次说人话
- 基调：喜剧顶点。每个科的部署都自洽、都庄严、都只对自己那条战线负责

**第三幕 · 战报**
- 目标：面对互相矛盾的化验结果，决定信谁
- **mustEvents**：出现一条与初步判断相反的检查结果；病历里出现第一处「记歪」；感染科公开表示怀疑又自我否定
- 机制：从本幕起，每幕至少产出两条 `record-N`（病程记录条目）

**第四幕 · 矛盾**
- 目标：在互斥的治疗方案里拍板，承受代价
- **mustEvents**：必须有一次「上 A 就伤 B」的硬抉择；必须有一次科室因被绕过而记恨（`sys-factions` 变动）
- 这是全作重心：喜剧到此转为「没人笑得出来」

**第五幕 · 夜班**（强制锚点，`autoAdvance: true`，`minTurnsInPhase` 保证足量铺垫）
- 目标：突发事件无法回避，只能决定以何种姿态面对
- 铁律：**不许给任何能躲开的选项**；玩家救不救得回来由掷骰 + 前面的轴决定，不由选择题决定
- **mustEvents**：夜间急变；一次真随机掷骰决定生死走向；护士长做出全场唯一诚实的行为

**第六幕 · 交班**
- 目标：看清「病历上的病人」与「床上的病人」是不是同一个人
- **mustEvents**：病历被当众念出；至少一处记录与事实不符被点破（或没人点破）；终局选择
- 收尾：玩家的最后一个动作不是医疗决策，而是**在病历上签字**

## 四、派系（七个科室）

每科一条战线、一套话术、一个盲区。`sys-factions` 记录影响力（七项，和为 100）。

| 科室 | 主张（它自己信的那句） | 语言风格 | 上升条件 | 盲区（它看不见的） |
| --- | --- | --- | --- | --- |
| **内分泌科** | 血糖是一条锁链，一处断了全盘皆乱（「确如常山之蛇」） | 系统工程口吻，爱用「整体构想」「联动」 | 血糖波动被记录、玩家按它调胰岛素 | 只算糖，不算激素本来就该升糖 |
| **风湿科** | 原发病不压，一切都是治标（「做总预备队」） | 逐条下达命令，爱说「我补充一点」 | 免疫指标活跃、玩家用激素/单抗 | 免疫压下去，感染就有了窗口 |
| **血液科** | **够不够格上化疗，要看血象和全身评估**（林医生） | 谨慎、讲条件、被全场催 | 玩家同意先评估再上治疗 | 拖久了肿瘤不等人；它自己也知道 |
| **感染科** | 病原学证据说话（「NGS 结果，我没有理由否定」） | 自我说服又自我否定的独白体 | 出现阳性结果、发热 | 定植不等于致病；它比谁都清楚，但不敢赌 |
| **消化科** | 先把肠道清干净，镜子才看得见（「肠镜畅通无阻」） | 具体、动作感强、略带得意 | 消化道症状被处理 | 全套清肠对虚弱病人本身是打击 |
| **心内科** | 循环稳不住，什么都白搭（「我不要他的伤亡数字，我只要人命」） | 电报体、短句、急 | 出现心律失常、血压波动 | 只顾循环，会否掉感染源的排查 |
| **呼吸科** | 这里是历代征战的古战场（「肺脏古战场」「优势在我」） | 史诗腔、纵横捭阖 | 氧合恶化、影像进展 | 把每一次变化都读成自己的战役，忽略别人那条线 |

**护士长**不属于任何派系，是全场唯一说人话的人（对应蚂蚁包里的**蚁后**与**逆**）：她掌握病人真实的反应——疼不疼、睡没睡、家属在走廊哭了多久——而这些**不在任何一份化验单上**。她的台词永远是短句、具体、不打比方。她越具体，那七个科室的宏大叙事越荒谬。

## 五、状态变量（挂在账本 `notes`，玩家 `/state` 可见）

| 变量 | 取值 | 谁在改 | 含义 |
| --- | --- | --- | --- |
| `sys-glucose` | 0-100 | 叙述者 | 血糖战线稳定度（低 = 乱） |
| `sys-immune` | 0-100 | 叙述者 | 免疫抑制强度（越高越压得住原发病，也越容易感染） |
| `sys-marrow` | 0-100 | 叙述者 | 骨髓储备（化疗/感染消耗） |
| `sys-infection` | 0-100 | 叙述者 | 感染负荷 |
| `sys-circulation` | 0-100 | 叙述者 | 循环稳定度 |
| `sys-oxygen` | 0-100 | 叙述者 | 氧合 |
| `sys-record-drift` | 0-100 | **旁侧记账模型** | 病历与事实的偏差度（本作签名变量） |
| `sys-family-trust` | 0-100 | 叙述者 | 家属信任 |
| `sys-factions` | 七个科室 + 护士长 | 叙述者 | 影响力分布 |
| `record-N` | 文本 | 旁侧记账模型 | 病程记录条目，允许记歪 |

**关键约束**：这些**不由玩家直接改**。玩家想让某个轴好转，只能通过下医嘱、会诊、谈话——不能点按钮。

## 六、签名机制：病历即经文

**一句话**：病历上写的那个病人，和床上的那个病人，永远不是同一个人；而玩家可以亲眼看到自己被写成了什么。

三层实现，逐层加深：

1. **默认（零代码）**：叙述者卡写死「记录规则」——每幕至少产出一条病程记录，并如实呈现它的走样。条目落进账本，`/state` 可见。
2. **自动（推荐补丁）**：把记账员的 system 提示换成「病历模式」，每回合结构化产出 `record-N`，content 用
   `{"as":实际发生了什么, "recorded":病历怎么写的, "drift":歪在哪}`。要求 `recorded` 必须与 `as` 有可辨识偏差，且偏差方向符合当前话语权最大的科室——内分泌记为「系统性调整」、风湿记为「按计划推进」、感染记为「已排除」、心内记为「生命体征平稳」、护士长记为「家属要求……」。
3. **签字（第六幕）**：玩家最后一件事是在病历上签字。签字前可以逐条读，读了也不能改——**能改的那叫事实，不能改的那叫记录**。

## 七、神谕卡与掷骰

**神谕卡（医嘱 / 会诊意见）**，四个固定方向 + 自由输入：

| 方向 | 含义 | 代价模式 |
| --- | --- | --- |
| 照单全收 | 按某科字面执行 | 该科影响力暴涨，其他轴被挤压 |
| 折中 | 各让一步 | 两边都不满意，效果打折 |
| 压住不发 | 先观察，什么都不加 | 时间流逝，原发病进展 |
| 越级拍板 | 绕过某科自己定 | 被绕过者记恨（`sys-factions` 变动 + 后续报复） |

**掷骰（并发症）**：夜班急变、输液反应、造影剂过敏、输血反应、痰培养回报。意义与蚂蚁包一致——**你不是故意作恶，只是无法精确控制**；这是「主角不是坏人，体系才是」的物理基础。

## 八、结局（六个）

判定依据：状态变量 + `decisions.jsonl` 的历次拍板留痕。

| 结局 | 触发 | 内容 |
| --- | --- | --- |
| ① **出院**（默认） | 病人活着出院，无重大事故 | 病历写得漂漂亮亮，家属千恩万谢。**没有任何人知道那天夜里发生过什么**——包括你。最接近原作的黑色结局 |
| ② **死亡讨论** | 病人死亡 | 事后复盘会：每个人说的都是真话，每个人都没有责任。文本停在主任那句「大家都辛苦了」 |
| ③ **转院** | 玩家多次选择上交 | 烫手山芋送走。下一站的会诊记录传回来，措辞与你写的一模一样 |
| ④ **家属签字** | 把关键决定推给家属 | 赌注从医学问题变成家庭问题。签字那一刻，走廊里没有人说话 |
| ⑤ **主任叫停** | `sys-record-drift` 过高 / 重大冲突 | 上级介入，你被「保护性」调离。病历在你走之后被重写了一遍 |
| ⑥ **教科书病例** | 活下来但代价巨大 | 三个月后病房讨论会拿你这一例讲课。PPT 上写着「本例的成功经验」 |

## 九、美术方向（与蚂蚁包**完全相反**，顺带解决"渗人"问题）

蚂蚁包是**微距昆虫摄影 + 宇宙恐怖**；本战役走**指挥所 / 档案**一路，明确避开身体与血：

- **画面里只出现**：作战地图、沙盘、化验单、病历纸、红蓝铅笔、老式电话与电报、夜间走廊的灯、值班室的钟
- **铁律（硬性）**：**不画病人身体、不画血、不画器官、不画侵入性操作、不画任何人体局部**。恐怖与重量靠**文字、纸、地图与时间**传达，不靠生理刺激
- 色调：冷（青灰 / 铅白 / 台灯暖点），与蚂蚁包的钠灯暖黄形成对照
- 六幕各一张 + 图谱一张（七个科室 + 护士长，用**作战序列图**的形式，不用人像）

这套方向有三个好处：与蚂蚁包差异化明显；程序化 SVG 极好生成（地图、纸张、表格都是几何图形）；**从根上避免了队友那种「看虫子不适」的问题**。

## 十一、三条铁律（写进 `card-neike.json`，不可删）

1. **绝不给诊疗建议**：所有诊疗情节都是夸张修辞。任何看起来像真医嘱的内容，必须由叙述者以荒谬化的方式呈现，且首屏与结局页有明确声明。
2. **病人的痛苦不是笑料**：笑点永远在**话术**与**体系**上，不在病本身。禁止把症状、疼痛、死亡写得好笑。这一条凌驾于"要好笑"之上。
3. **不替玩家做决定**：每一个拍板都必须来自玩家本人。可以给选项、可以逼时间，但不能替他选。

## 十二、风险与取舍

| 风险 | 处理 |
| --- | --- |
| 医学细节写错，被专业读者挑刺 | 刻意模糊具体剂量与流程；喜剧来自**话术结构**而非医学事实；请一位临床背景的人过一遍 |
| 冒犯真实经历过这些场景的人 | 第二条铁律 + 结局不嘲讽具体的人，只嘲讽体系 |
| 与蚂蚁包共用仓库导致混淆 | 独立战役目录 + 独立 Vercel 项目；两个包共用运行时，互不可见 |
| 抽象层改动波及现网 | 阶段一要求「与改动前逐像素一致」作为硬验收；先本地后线上，且原站可随时回滚 |
| 做成之后没人玩 | 先做阶段一（约半天，且对现有项目本身有价值），看到抽象层真的松了再投入文本量 |
