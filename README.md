# 优势在我 · The Advantage Is Mine

> 一款基于**状态化 LLM Agent 运行时**的互动叙事游戏。
> 你是一个内科当班主管医生——不是主任，不是某个科的专家，是那个必须把所有人的意见收拢成一句话、然后签字的人。
>
> 戏仿作品，灵感来自知乎答主 **Action Potential** 的回答《大决战·内科》。为 AI 演绎，非原作者作品。
> **全部诊疗情节为夸张修辞，不构成任何医疗建议。**

---

## 一、这是什么

凌晨四点二十，留观区推进来一张加床。主诉含糊，查体拿不准，化验单还没回来。你手里的初诊判断，会被接下来每一份化验单反复审判；而走廊那头，七个科室的电话已经在响了。

每个科室都会给你一份**战略构想**：内分泌谈的是血糖这条不能断的锁链（「确如常山之蛇」），风湿谈的是总预备队，血液科的林医生把条件一条条念完才肯动，感染科在心里跟自己打架，消化科说镜子一路畅通，心内科只在出事的时刻来电，呼吸科把肺讲成一片历代征战的古战场。

**每一份都对。合起来就互相打架。**

激素压得住原发病，却把血糖推上去、把感染的窗口打开；治疗要压骨髓，而血象还没回来；抗菌药要足量，可它压的是同一个免疫系统。你每往前一步，就有一条战线亮起红灯。

这个游戏的核心命题只有一句：**没有任何一个科室负责「整个病人」——那就是你的位置。**

## 二、六幕

| 幕 | 情境 | 你要面对的事 |
| --- | --- | --- |
| 一 · 入院 | 凌晨留观，主诉含糊 | 在信息极少时给出第一个判断，并决定先叫哪个科 |
| 二 · 会诊 | 各科鱼贯而入，各交一份战略构想 | 发现反驳不了任何一个科室 |
| 三 · 战报 | 化验单雪片般回来，互相矛盾 | 面对一条推翻你初步判断的结果 |
| 四 · 矛盾 | 治疗方案互斥，必须有人让路 | 亲手拍板，并承担代价 |
| 五 · 夜班 | 后半夜，监护仪的声音变了 | 在一分钟内做决定（**这一夜躲不掉**） |
| 六 · 交班 | 病历被当众逐条念出 | 在最后一页签上名字 |

六个结局（`assets/campaigns/neike/endings.md`）：出院、死亡讨论、转院、家属签字、主任叫停、教科书病例。

## 三、机制

详见 [`assets/campaigns/neike/MECHANICS.md`](assets/campaigns/neike/MECHANICS.md)。签名机制是**病历**：

> 病历上写的那个病人，和床上躺着的那个病人，永远不是同一个人。半夜里一个人拍的板，会被记成「经全科讨论后决定」；没人敢说的话，会被写成「已告知病情，家属表示理解」。玩家可以随时打开账本，读到一条刚出炉的、把自己拍板记成集体决议的记录。

其余机制全部复用运行时已有能力，**默认零代码改动**：状态变量存记忆账本（`/state` 可见）、医嘱与会诊意见复用神谕卡、并发症复用掷骰、六幕推进由主线导演按关键词 + 回合门槛驱动，第五幕夜班用 `autoAdvance` 做成**不可回避的强制锚点**。

**三条铁律**（写死在角色卡里，不可删）：①绝不给诊疗建议，所有诊疗情节都是修辞；②**病人的痛苦不是笑料**——笑点永远在话术与体系上，绝不在病本身；③不替玩家做决定，每一次拍板都必须来自玩家本人。

## 四、运行

前置：**Node.js ≥ 22**（原生运行 TypeScript）。运行时只依赖一个第三方包 `ws`（WebSocket 服务端），其余全部用 Node 内置能力手写：HTTP 服务、OpenAI 兼容客户端、上下文管理、向量召回。

```bash
npm install
cp .env.example .env      # 填自己的 API key
npm run web               # 打开 http://127.0.0.1:7620
```

模型走 OpenAI 兼容接口，`.env` 里要填：

| 变量 | 说明 |
| --- | --- |
| `WANGDACHUI_API_BASE` | 主模型 base url（OpenAI 兼容） |
| `WANGDACHUI_API_KEY` | 主模型 key（**回合配图也用这个 key**） |
| `WANGDACHUI_MODEL` | 主模型名 |
| `WANGDACHUI_FALLBACK_*` | 可选，兜底 provider（主模型失败自动切换） |

**斜杠命令**：`/state` 看账本（含病历与状态变量）· `/phase` 看幕进度 · `/lore 科室` 查世界书 · `/snap` 存档 · `/back` 回档。

**回合配图（AI 现场生成）**：每回合正文出完后，服务端异步再画一张插画，贴在消息下方。正文先出、图后补，全程不阻塞对话；图只走 UI，不进对话历史。取图走 `GET /api/illustration?sid=X`，**直接回图片字节**（不转 base64——省 25% 体积）。配置见 `.env.example`：`WANGDACHUI_ILLUSTRATION=0` 可整体关闭，`WANGDACHUI_ILLUSTRATION_MAX` 是每会话上限。

> 美术方向是**指挥所与病历档案**一路：作战地图、沙盘、病历纸、红蓝铅笔、老式电话、夜间走廊的灯。**硬性禁止画人体、血、器官、侵入性操作**——重量交给纸、灯、地图与时间，不靠生理刺激。
